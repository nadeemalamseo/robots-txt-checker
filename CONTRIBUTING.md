# Contributing

Contributions are welcome when they improve the checker for real users.

Before opening a change:

1. Explain the problem or use case.
2. Keep parsing behavior documented and testable.
3. Add or update tests for behavior changes.
4. Run `python -m unittest discover -s tests -v`.
5. Keep documentation accurate about crawler-specific differences and limitations.

Please avoid changes whose primary purpose is promotional linking, ranking claims, or marketing copy.
